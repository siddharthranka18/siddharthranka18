## 🏗️ Selected Projects

### 🛠️ Smart Airport Ride Pooling Backend
> **Intelligent ride matching engine featuring geospatial querying and strict transactional isolation[cite: 1].**
- Built optimized geospatial tracking with **MongoDB 2dsphere indexing**, achieving sub-300ms matching cycles[cite: 1].
- Implemented **optimistic locking policies** with failure retry queues to ensure data integrity under spike loads[cite: 1].
- Engineered a dynamic surge engine evaluating localized demand density, distance vectors, and pooling incentives[cite: 1].
- 🔗 **[Code Repository](https://github.com/siddharthranka18)**[cite: 1]

### 📮 Notification Engine
> **Production-ready asynchronous messaging microservice handling distributed notifications[cite: 1].**
- Backed by a high-throughput **BullMQ + Redis** job architecture managing task delays, custom retries, and failure states[cite: 1].
- Multi-channel support linking **Twilio SMS** and **Nodemailer** alongside adaptive backoff logic[cite: 1].
- Provides real-time event distribution to connected sessions via **Socket.IO** backed by MongoDB transaction logging[cite: 1].
- 🔗 **[Code Repository](https://github.com/siddharthranka18/notification-engine)**[cite: 1] · **[Live System](https://notification-engine-6zse.onrender.com)**[cite: 1]

### 🛒 AI Shopping Assistant
> **Conversational agent capable of parsing intent, evaluating product catalogs, and automating orders[cite: 1].**
- Leveraging **LangChain tool-calling schemas** integrated into Groq LLMs to trigger programmatic workflows[cite: 1].
- Employs **Vision LLM inference** for visual parsing and real-time reverse image matching pipelines[cite: 1].
- Deployed on a Streamlit frontend capturing context, persisting interaction states to a localized SQLite runtime[cite: 1].
- 🔗 **[Code Repository](https://github.com/siddharthranka18/shopping-agent)**[cite: 1]

### 📰 Dynamic News RAG Agent
> **Live retrieval-augmented generation engine pulling and synthesizing real-time web context[cite: 1].**
- Bypasses static parameter knowledge through automated scraping, chunk tokenization, and vector transformations[cite: 1].
- Utilizes localized **HuggingFace Embeddings (`all-MiniLM-L6-v2`)** maps paired with an in-memory **ChromaDB** pipeline[cite: 1].
- Fully autonomous execution yielding zero API generation costs for vector computing workflows[cite: 1].
- 🔗 **[Code Repository](https://github.com/siddharthranka18/dynamic-news-RAG_agent)**[cite: 1]

### 🎵 crossTune — Android Media System
> **Cross-platform structural media aggregator built directly over native Java implementations[cite: 1].**
- Powered by **Media3 ExoPlayer** loops running distinct foreground background services to maintain playback state[cite: 1].
- Real-time shared playback states and session sync managed globally through persistent **Socket.IO channels**[cite: 1].
- Secured using **Firebase OAuth** while linking multi-platform database syncs to dedicated Railway relational tables[cite: 1].
- 🔗 **[Code Repository](https://github.com/siddharthranka18/crossTune)**[cite: 1]

### 📄 AI Resume Analyzer
> **Algorithmic career parsing model parsing documents for multi-layered metric evaluation[cite: 1].**
- Features dual-tier screening matching raw keyword lists alongside **Groq LLaMA contextual token processing**[cite: 1].
- Interactive user space written entirely in React using a customized ultra-dark minimalist console design theme[cite: 1].
- Fully transactional API routes tracking document profiles dynamically in centralized MongoDB clusters[cite: 1].
- 🔗 **[Code Repository](https://github.com/siddharthranka18/resume-analyzer)**[cite: 1] · **[Live Application](https://resume-analyzer-lovat-delta.vercel.app)**[cite: 1]
